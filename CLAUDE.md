# Claude uchun yo'riqnoma

## "Video yasa" deyilganda

Foydalanuvchi "video yasa" (yoki "reel yasa", "vediyo qil") desa, avval `video-kit/README.md` ni o'qing va
undagi uslub hamda ovoz vositalaridan foydalaning. Namuna: `video-kit/reference/namuna_reel.mp4`.

Javoblarni o'zbek tilida yozing.

## Bepul API (NVIDIA NIM, Baseten, OpenRouter)

Bepul API key olish va ularni Claude Code / Cursor'ga ulash bo'yicha qo'llanma `free-api/README.md` da.
Key'lar faqat `free-api/.env` da turadi (git'ga kirmaydi). Hech qachon key'ni commit qilmang.
