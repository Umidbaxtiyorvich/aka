# Keyingi bosqichlar

Har bir bosqich: kod → testlar → haqiqiy ishga tushirib tekshirish → commit.

1. **Ollama integratsiyasi** — Windows'da real model bilan sinash, javob vaqti va RAM o'lchovi.
2. **Business Intelligence (CSV/Excel)** — mahsulot, qoldiq, kirim/chiqim importi; kam qolgan mahsulot, noto'g'ri narx, takroriy hujjat, foyda. Asl fayl o'zgartirilmaydi.
3. **POS Connector** — POS manzili berilgach: faqat o'qish rejimida sayt tuzilishini o'rganish (Playwright, siz kirgan sessiya), hujjat loyihasi → D-daraja tasdiq → kiritish → qayta tekshirish. CAPTCHA/2FA chetlab o'tilmaydi.
4. **Telegram Assistant** — bot (token Credential Manager'da), faqat ruxsat berilgan user ID'lar, bildirishnomalar, tasdiq ma'lumotini ko'rsatish.
5. **Internet tadqiqoti** — qidiruv, manba/sana/ishonch, injection himoyasi.
6. **Voice** — brauzer Web Speech API (internet talab qiladi) va mahalliy Whisper (75 MB–1.5 GB) o'zbek tili sifatini solishtirish; siz tanlaysiz.
7. **Video Studio** — FFmpeg: kesish, birlashtirish, 9:16, subtitr.
8. **Instagram** — Meta Graph API (Business/Creator akkaunt, Facebook sahifaga ulangan). Faqat API qo'llaydigan amallar.
9. **Self-improvement** — patch'ni alohida branch'da yaratish va testdan o'tkazish.
10. **Telefon qo'ng'irog'i** — tashqi SIP/telephony provayder (pullik). Narx oldindan ko'rsatiladi, siz roziligingizsiz yoqilmaydi.
